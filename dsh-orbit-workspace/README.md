# DSH Orbit Workspace Phase 1 bundle

This bundle provides the Phase 1 DSH shell for the Orbit Workspace roadmap:

- a localized Orbit Workspace entry in the DSH sidebar;
- a global main panel with loading, error, empty, and disconnected states;
- capability diagnostics for Workspace, Session, Remote, credentials, and settings services;
- effect-owned Host and Client lifecycle cleanup.

Workspace and Session operations remain Phase 2 work.
