# 个人微信 iLink 使用说明

这份说明适用于已经在 Orbit Safe Claw 中完成微信 iLink 扫码，并重启应用的情况。

微信接入可以理解成 Orbit Safe Claw 的一个私聊入口：你在微信中选择一个 Bot，再发送任务；任务仍由 Orbit Safe Claw 后端执行，完成后把最终答复发回微信。

## 先确认微信已经上线

在 Orbit Safe Claw 中打开 **Admin Center → 消息 → 消息网关**，确认这三项：

- **微信启用**：是
- **微信账号**：已经绑定账号
- **微信连接**：`connected` 或“已连接”

扫码成功后，面板会提示“配置已保存，需要重启应用”。应用会自动保存 `WEIXIN_ACCOUNT_ID`；如果 `WEIXIN_ALLOWED_USER_IDS` 还是空的，也会把本次扫码用户的 iLink ID 写入白名单。重启完成后网关才会开始接收消息。微信 iLink 使用 HTTP 长轮询，不需要配置公网 Webhook，也不需要把 Orbit Safe Claw 暴露到公网。

微信只接收 `WEIXIN_ALLOWED_USER_IDS` 中用户发来的个人私聊文本。这里的“用户 ID”指 iLink 消息里的发送者/私聊 ID，通常不是你个人资料里的微信号、手机号或昵称；`WEIXIN_ACCOUNT_ID` 是 iLink Bot 自己的账号 ID，两者用途不同。首次扫码时，空白白名单会自动加入扫码用户的 iLink ID；如果已经有白名单，系统会保留现有名单。管理员也可以在消息网关面板的“个人微信配置”中补充其他用户，保存后需要重启应用。白名单为空时，微信接入不会启动。

## 第一次使用

请在与 iLink Bot 的**个人私聊**中按下面顺序操作：

1. 发送 `/help`。
2. 在回复中找到可用的 Bot 别名，例如 `main` 或 `dev`。
3. 使用 `to <Bot 别名> <任务正文>` 发送第一条任务。

例如，假设可用 Bot 别名是 `dev`：

```text
to dev 帮我分析一下当前项目的启动流程
```

这里的 `dev` 是 Orbit Safe Claw 中的 Bot 配置别名，不是微信昵称。每条任务都要带上 `to` 和 Bot 别名；直接发送普通问句时，网关会返回帮助说明。

任务也可以写成多行，适合发送代码或较长的需求：

```text
to dev
请检查这个错误的原因，并给出修复步骤：
TypeError: cannot read properties of undefined
```

## 常用命令

| 命令 | 用途 |
|---|---|
| `/start` 或 `/help` | 查看可用 Bot 别名和帮助 |
| `to <别名> <正文>` | 在指定 Bot 的当前会话中执行任务 |
| `to <别名> /new` | 新建并切换到一个会话，旧历史保留 |
| `/status` | 查看当前微信绑定会话的状态、任务和上下文余量 |
| `/stop` | 停止当前微信绑定会话中的运行任务 |
| `/config <别名>` | 查看执行模式、模型、思考强度和集群开关 |
| `/config <别名> model <值>` | 修改指定 Bot 的模型 |
| `/config <别名> reasoning <值>` | 修改指定 Bot 的思考强度 |
| `/config <别名> cluster on` | 开启指定 Bot 的集群 |
| `/config <别名> cluster off` | 关闭指定 Bot 的集群 |
| `/host` | 查看宿主和公网入口状态 |
| `/host restart` | 请求重启后端并获取确认提示 |
| `/host restart confirm` | 在确认有效期内执行后端重启 |

配置命令会修改 Bot 配置，下一轮任务使用新值。模型和思考强度必须填写该 Bot 当前 CLI 支持的值。

一个完整的连续对话可以这样使用：

```text
to dev 帮我设计一个登录页的改造方案

to dev 再把方案拆成三个可以直接执行的步骤

to dev /new

to dev 从一个空白会话开始，列出当前工作区的目录结构
```

## 会话是怎样工作的

第一次向某个 Bot 发送任务后，微信私聊会绑定到这个 Bot 的当前会话。之后继续使用同一个别名，任务会沿用这段历史。

微信和 Web、Telegram 共用 Bot 会话和历史。微信中执行的任务可以在 Web 中继续查看；Web 在同一个 Bot、同一个会话中执行任务时，绑定到该会话的微信私聊也会收到最终答复。

当前微信入口固定使用每个 Bot 的 `main` Agent。需要切换到一段全新的上下文时，发送 `to <别名> /new`。Web 切换会话后，微信端不会自动迁移到新会话，使用 `/new` 可以明确完成切换。

## 回复会以什么形式到达

- 微信收到最终答复、错误信息、停止结果和必要的控制命令结果。
- CLI 的实时输出、trace、状态预览和集群子任务进度不会逐条推送到微信。
- 较长答复会自动拆成多条微信消息。
- 最终答复末尾的 `context left` 表示当前会话剩余上下文余量，可以用来判断是否需要新建会话。

## 当前支持范围

- 个人微信私聊文本。
- 通过 Bot 别名选择 Orbit Safe Claw 中已启用的 Bot。
- 普通微信群消息、图片、视频、语音、文件、微信卡片和消息编辑目前不会触发任务。

## 常见问题

### `/help` 没有回复

请让管理员检查 Admin Center → 消息 → 消息网关中的连接状态，并确认你的 iLink 私聊/发送者 ID 已加入 `WEIXIN_ALLOWED_USER_IDS`。这个值通常不等于微信号；当前面板只显示白名单数量，不显示未授权消息里的原始发送者 ID。白名单或环境配置修改后需要重启应用。还要确认消息发给的是已完成 iLink 绑定的个人微信 Bot。

### `/help` 有回复，但任务提示 Bot 不可用

先重新发送 `/help`，使用帮助中的完整 Bot 别名。例如 Bot 别名为 `dev` 时，命令应写成：

```text
to dev 帮我检查这个问题
```

### 任务执行了，却看不到过程

这是当前微信入口的正常行为。微信只推送最终答复；需要查看实时状态、trace、审批或集群子任务时，请打开 Web。

### 微信连接需要重新登录

在 Admin Center → 消息 → 消息网关中重新开始扫码，使用微信确认二维码，等待状态变为“已确认”，然后重启应用。

### 在微信群里发送消息没有反应

当前接入只处理个人私聊文本，普通微信群消息会被忽略。
