# Remote workspace

Remote SSH workspace: host="remote.example", root="/work/project".
Remote OS: POSIX; commands run in /bin/sh.
This local working directory is only an agent control directory; it contains no project source or tests. Uploaded chat attachments are stored locally under attachments/ in this control directory. An 'Attachment path:' in the user message is a local absolute path: read or process it with local tools (Pi: local_read/local_bash). Keep attachment processing outputs alongside the input attachment. Perform ALL project reads, edits, searches, commands and tests on the remote workspace using tcb-remote MCP exec/read/write/edit/list (Pi: remote_exec/remote_read/remote_write/remote_edit/remote_list; read/write/edit/bash/ls are also routed remotely). Paths are remote, relative to the remote root. Before changes, read the remote repository's AGENTS.md, CLAUDE.md and applicable nested instructions. Batch related commands with exec.commands; use bounded read ranges and rg to limit output. Use edit with exact old_text/new_text; ambiguous matches fail. If the bridge fails, report the error; do not fall back to local files, local tests or a separate SSH client. The CLI's built-in tools still run locally: this routing guidance is not a filesystem sandbox.
